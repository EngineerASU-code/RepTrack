# Подтверждённый контекст рабочей папки

- Основное приложение находится в `GASS_Configurator/`; перед работой с ним прочитай `GASS_Configurator/AGENTS.md`.
- `docs/configurator/` содержит описание и результаты ручных проверок, `tasks/` — требования к развитию приложения. Старые результаты не подтверждают текущую исправность.
- `tools/maintenance/` и `tools/omniroute-fallback/` содержат служебные Node.js-скрипты, `tools/windows-mcp/verify.py` — Python-проверку подключения MCP. Это отдельные инструменты, не зависимости сборки Configurator.
- Не запускай служебные скрипты как обычные тесты приложения: среди них есть изменение конфигурации, запуск процессов и обращения к внешним AI API. Для проверки синтаксиса `.mjs` достаточно `node --check <файл>` (локальный runtime: `tools/node-v24.22.3-win-x64/node.exe`).
- Не читай резервные копии БД, хранилища провайдеров и профили с ключами для определения стека или запуска проверок качества.
- На момент первоначальной проверки в корне нет Git-метаданных; не считай доступность `git status` или diff гарантированной.
