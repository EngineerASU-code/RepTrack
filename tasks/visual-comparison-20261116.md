# Финальное визуальное сравнение Android-кандидата C01/C03

16 ноября 2026 · Источник требований: `design/VISUAL_SPEC.md` · Инструмент: `tools/visual-compare/compare.ps1` · Результаты: `design/acceptance/visual-acceptance/visual-comparison-20261116-final-candidate/`

## Источники

- C01 и C03 — полные скриншоты Android debug APK из `design/acceptance/visual-acceptance/run-20261116-final-candidate/visual-acceptance/`.
- Метаданные кандидата: Android API 35, viewport 411×914 dp, density 2.625, font scale 1.0, тема Purple Pro, синтетический demo-профиль, вариант debug. APK собран из изменённого рабочего дерева на базе `ce9eb93b8e7136c938a32061d30279711fe82e4e`.
- R01 — два телефона на `design/Фиолетовый Pro_ концепт RepTrack.png`: первый экран сопоставлен с C01, второй — с C03.
- R02 — `design/Главная RepTrack_ фитнес-прогресс.png`; сравнивается с C01. R03 — `design/Тёмный интерфейс тренировки RepTrack.png`; сравнивается с C03.

## Нормализация

Кандидат помещается на холст 1080×2400 px без растяжения. Область референса масштабируется равномерно правилом `min(1080 / width, 2400 / height)` и центрируется на том же холсте. Overlay кладёт референс поверх кандидата с прозрачностью 50%. Параметры и координаты сохранены в `geometry.json`.

| Пара | Crop референса | Масштаб ref → холст | Позиция ref |
|---|---:|---:|---:|
| C01–R02 | `(0,70) 841×1760` | 1.284185× | `(0,70)` |
| C03–R03 | `(0,70) 841×1760` | 1.284185× | `(0,70)` |
| C01–R01 | `(30,178) 269×552` | 4.014870× | `(0,92)` |
| C03–R01 | `(329,178) 278×552` | 3.884892× | `(0,128)` |

R01 содержит экраны на презентационной доске. Эти пары сравнивают общий экран и композицию; они не регистрируют системные области попиксельно и не являются численной оценкой сходства.

## Наблюдения

- C01 показывает брендированную шапку, карточку следующей тренировки с гантелью, заметную кнопку старта, цикл, последнюю сессию, график и нижние пять разделов. Это поддерживает структуру концепта R01. R02 выполнен в Lime Energy, тогда как кандидат — Purple Pro; данные и плотность карточек у них также различаются.
- C03 использует отдельный экран тренировки: первая карточка раскрыта, остальные свёрнуты, нижняя навигация скрыта ради управления тренировкой. На полном нижнем кадре все четыре упражнения видны над закреплённой кнопкой завершения. R03 содержит шесть упражнений и другой прогресс/таймер, поэтому детали данных и высота карточек не совпадают.
- C06 показывает упражнение, иллюстрацию, текстовые шаги, карту целевых мышц и источник инструкции. C11 подтверждает график и нижние блоки рекордов/истории. Для длинных экранов сохранены верхние и нижние кадры; C14 также снят сверху и снизу.
- Те же сравнения C01/C03 построены для второго контрольного viewport 360×800 dp; кадры лежат в `run-20261116-final-candidate-360/visual-acceptance/`, их нормализованные пары — в `visual-comparison-20261116-final-candidate-360/`.

## Ограничения

- R02/R03 используют лаймовую тему, кандидат — Purple Pro. Тестовые числа отличаются от чисел концептов.
- Сравнение подтверждает наличие ключевых блоков и общий характер навигации, но не полное визуальное соответствие. Рамки блоков по критериям 4/2 dp не снимались отдельно; ручной визуальный прогон в эту автоматическую приёмку не включён.
- Сгенерированные exercise-изображения служат для узнавания упражнения и не подтверждают безопасную технику. Для вариантов без проверенного справочника сохраняется текстовое состояние «не подтверждено».
