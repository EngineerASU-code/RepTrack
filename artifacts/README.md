# Сборочные артефакты RepTrack

Устаревший APK удалён из рабочего репозитория. Свежая debug-сборка создаётся из исходников; требования и команды описаны в [ресурсах сборки](../docs/project/BUILD_RESOURCES.md).

Результат: `android/app/build/outputs/apk/debug/app-debug.apk`.

APK и контрольные суммы не хранятся в Git. Debug APK предназначен для локальной проверки; release-подпись настраивается отдельно.
